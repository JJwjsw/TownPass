# 字型準備

本機目前使用以下字型檔，對應 pubspec.yaml 的 PingFangTC family：

- PingFangTC-Thin.otf
- PingFangTC-Ultralight.otf
- PingFangTC-Light.otf
- PingFangTC-Regular.otf
- PingFangTC-Medium.otf
- PingFangTC-Semibold.otf

由於專案未附可再散布的授權證明，字型二進位檔暫不提交公開 Git；既有本機檔案不刪除。
從 repo 重新建置時，須先取得有權使用的上述字型並放入本目錄，或另行將 pubspec.yaml 與程式中的字型設定改為可再散布字型。
這個 repo 的字型準備仍是建置前置條件，不能宣稱乾淨 clone 後已包含所有必要資產。
