# 聊天互動更新

- 首頁 AI 浮動按鈕可拖曳，限制於可用內容區；閒置五秒後淡化為 30%，觸碰恢復。開啟中阻擋重複啟動。
- 聊天輸入框 autofocus 使用原生 Android IME；保留一般文字輸入、建議與 Gboard 語音輸入能力。
- 點輸入框以外內容（含可選取文字）、面板上方空白處會 unfocus，聊天面板不因此關閉；點輸入框可再次叫出。
- Gboard 與 Google 系統 VoiceInputMethodService 已在現有模擬器，show_ime_with_hard_keyboard=1。App 不自行收音，語音輸入由鍵盤處理，需要使用者允許鍵盤的麥克風權限。
- 導航不再依 enum 順序推算服務，改為明確 id 對照；接受舊／新服務程式路徑與 Windows 分隔符。
- 已存在的目的地允許再次開啟；活動入口最多等待五秒讓既有資料載入，避免剛開首頁便點擊失敗。
- 空 url 或既有程式尚無目的地的服務仍顯示原有缺少／不支援提示，不編造網址。遠端網頁可用性取決於伺服器與網路，不保證每個未實作項目都有連結。

驗證：16 項互動／導航／檢索單元及 widget 測試通過，修改範圍靜態分析 No issues found。
真實語音辨識與使用者麥克風收音尚未驗證，需在裝置上點鍵盤麥克風試說。
